# HTML Basics — Systemizer Lessons

Навчальні матеріали курсу **Vibe Coding & Design Engineering** до уроків
**HTML Basics** та **CSS Basics for Design Engineers**.

Це сторінка Lessons із продукту Systemizer: два lesson-cards, згенеровані
з Figma-макета через Figma MCP. Структура коду один в один повторює
панель Layers у Figma-файлі, а стилі побудовані на дизайн-токенах із макета.

## Файли

| Файл | Що це |
|---|---|
| `index.html` | Структура сторінки — «що тут є» |
| `style.css`  | Стилі — «як воно виглядає»: токени в `:root`, Auto Layout через `flex` |

## Як відкрити

1. Завантажте обидва файли в одну папку (Code → Download ZIP)
2. Подвійний клік по `index.html` — сторінка відкриється в браузері
3. Right click → `Inspect` — і читайте структуру, як панель Layers

## Що з цим робити на уроках

- **HTML Basics:** прочитати структуру, знайти parent/child/sibling,
  «зламати без страху» через Inspect
- **CSS Basics:** зробити ребренд, змінюючи лише токени в `:root`;
  додати `:hover`; додати третю картку через AI

> Файл неможливо зіпсувати: Refresh повертає все. Ламайте сміливо.
