# Systemizer Lessons — навчальний репозиторій

Матеріали блоку **Code Basics для Design Engineers** курсу
**Vibe Coding & Design Engineering**.

Це сторінка Lessons із продукту Systemizer: lesson-cards, згенеровані
з Figma-макета через Figma MCP. Проєкт росте разом з уроками — від двох
статичних файлів до React-застосунку з токен-системою, Tailwind і темною
темою. Кожен стан збережений окремою гілкою.

## З чого починати

**Приєднуєтесь із першого уроку** — вам потрібна гілка `main` (вона відкрита
за замовчуванням): `Code → Download ZIP` → розпакувати → подвійний клік по
`index.html`. Реєстрація на GitHub не потрібна.

**Приєднуєтесь із четвертого уроку або пізніше** — зробіть Fork цього
репозиторію, клонуйте його в GitHub Desktop і перемкніться на гілку,
названу як **попередній** урок: вона містить проєкт у тому стані, з якого
починається наступний. Якщо це React-проєкт (усе від гілки `react` і далі) —
перед запуском попросіть Claude Code: `Install dependencies and start the
dev server`.

## Гілки

| Гілка | Стан проєкту | Відповідає урокам |
|---|---|---|
| `main` | Два статичних файли + README. **Стартер** | HTML - basics, CSS - basics, Design Engineer flow |
| `html-jsx` | Картки стали компонентом `LessonCard`, без запуску | після HTML → JSX (React) |
| `react` | Vite-проєкт, три картки, hot reload | після React |
| `react-components` | Ціна, `Chip`, `Button` з hover | після React Components |
| `tokens-css` | Токен-система: primitives → semantic | після Tokens CSS |
| `tailwind-css` | Tailwind на наших токенах, `Button` мігрований | після Tailwind CSS |
| `course` | Повний стан: shadcn, темна тема, перемикач | після Shadcn — референс |

Правило одним рядком: **гілка називається як урок і містить проєкт після
нього — щоб почати наступний, беріть її.**

Чекпоінти — зліпки, їх не вливають у `main` і не редагують.
Свою роботу ведіть у власному форку.
